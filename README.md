# 抖音网页版个人优化

把抖音网页版改成「能安静看视频」的样子 —— 悬浮侧边栏、画面净化、精准直播过滤、真实在线人数、画质与倍速增强，**所有功能都能单独开关**。

当前版本 **9.52** · 许可证 MIT · 仅匹配 `www.douyin.com` 与 `live.douyin.com`

---

## 📥 怎么用（第一次装，看这一节就够）

### 第 1 步：装一个脚本管理器

| 浏览器 | 推荐扩展 |
| --- | --- |
| Chrome / Edge / 360 / QQ 浏览器 | [Tampermonkey（篡改猴）](https://www.tampermonkey.net/) |
| Firefox | [Violentmonkey（暴力猴）](https://violentmonkey.github.io/) |

装完确认工具栏上有它的图标。Chrome / Edge 新版可能要求在扩展详情里把「允许用户脚本 / 开发者模式」打开，否则脚本装不进去。

### 第 2 步：安装本脚本

点这个链接 → [抖音网页版个人优化-9.52.user.js](https://raw.githubusercontent.com/fengyulll/DouyinWebOptimize/main/抖音网页版个人优化-9.52.user.js)

脚本管理器会弹出安装页面，点「安装」即可。

> 也可以在仓库文件列表里点开 `.user.js`，选 **Raw**，脚本管理器同样会接管。

### 第 3 步：打开抖音

访问 <https://www.douyin.com> 或 <https://live.douyin.com>，脚本自动生效，不需要额外授权。

按 **`Alt + S`** 唤出设置面板（屏幕正中），里面每个功能都是一行开关，想关哪个关哪个，改完即时生效。

### 第 4 步：记住几个常用快捷键

| 快捷键 | 作用 |
| --- | --- |
| `Alt + S` / `Esc` | 打开 / 关闭设置面板（可改） |
| `Shift + 1` | 切回原速 1.0x（可改） |
| `Shift + 2` | 切到设定倍速，默认 2.0x（倍速值可改） |
| 双击画面 | 切换网页全屏（代替原来的双击点赞） |
| 左键单击画面 | 播放 / 暂停（视频流页默认开，直播间默认不接管） |
| 左键长按 | 模拟按 `D` 键（仅视频流页） |
| 中键 | 视频流页切评论区；直播间收起 / 展开聊天室 |
| 滚轮 | 直播间画面内滚轮调音量，步进可在设置里改 |

### 第 5 步：以后怎么更新

仓库里更新 `.user.js` 之后，在脚本管理器的「已安装脚本」里点 **检查更新**，或直接重新打开安装链接覆盖安装。设置会保留，不用重新配。

### 遇到问题怎么反馈

打开设置面板 `Alt + S` → 拉到底部「排障诊断」→ 点对应项目的 **复制** 按钮 → 把复制出来的文本贴出来。

这些诊断只是把结构化信息复制到剪贴板，不上传、不改设置，比自己描述「它不生效」有用得多。

## 简介

打造纯净、可控的抖音网页版观看体验：左侧导航悬浮化、画面去干扰、直播间信息按需过滤、摄像头小窗随手摆，全部功能都能单独开关。

> **💬 欢迎提建议：** 脚本会持续维护，但我一个人的想法和视角有限，很多实际使用场景可能想不到，欢迎随时反馈建议、需求和 bug——好的坏的都行，我会参考着优化。你的使用场景，可能就是我下一步要补的功能。

## 核心功能

* **沉浸式悬浮侧边栏**：左栏变为纯色圆角悬浮态，鼠标靠近左缘展开、移开或移出窗口自动收起；live 域名搜索框自动补偿居中；关闭「直播间悬浮侧边栏」后还原抖音原生侧栏。
* **自定义视频黑名单**：一行一个关键词或作者名，命中即自动跳过，还你干净信息流；命中时会提示命中的关键词。
* **推荐流自动跳过**：默认自动划走广告视频与推荐直播卡片；两项可分别关闭，跳过方式可选「只划走（能划回来看）」或「点不感兴趣（不再推荐）」，互不影响。
* **画面净化**：屏蔽礼物栏、礼物特效、点赞飘心、展馆/送礼悬浮弹窗、切换播放按钮及客户端下载引导；自动关闭「长时间无操作，已暂停播放」弹窗。
* **精准直播过滤**：自动关掉弹幕设置面板里的「送礼信息」与「福袋口令」两个开关，并有聊天室文本兜底；静音礼物音效而不影响主视频声音。
* **真实在线人数**：网络响应、React fiber（`room_view_stats`）、全局与内联数据多通道取数，替换「10万+」这类模糊值；主动轮询间隔可在 1~30 秒间调整，默认 2 秒，页面推送一到就刷新，带量级校正与异常小值护栏，取不到精确值也不会冻在错数字上。
* **直播间默认最高画质**：进入直播间自动切到「原画」，进房前几秒高频重试，切到即停；并写入本地偏好供下次生效。
* **视频流默认最高画质**：推荐流按「超清 / 4K」起播，源没有该档位时逐级回退，与直播画质互不影响。
* **摄像头小窗独立浮出**：聊天室上方那块摄像头画面自动浮到播放区，等比放大、任意拖动、右下角拖拽改大小；识别不准可在面板里填选择器，或点「复制候选」一键导出。
* **倍速快捷键**：`Shift+1` 原速、`Shift+2` 切到设定倍速（默认 2.0x，可选 0.75/1/1.25/1.5/1.75/2/3）；换视频后自动保持，直播流自动跳过。
* **倍速记忆同步**：可让倍速同时写入抖音自己的倍速栏，下一条视频也按它播放；不想被抖音记住可单独关闭。
* **防静音续播**：点「继续看播」或播放恢复后自动解除抖音默认静音；一旦手动动过音量控件，本房间不再自动解除，长时间静音也不会被打扰。
* **评论区搜索词高亮**：把评论区里「点一下会触发抖音搜索」的词染成青色，并隐藏小放大镜图标。
* **单击画面播放 / 暂停**：视频流页左键单击画面即可播放 / 暂停（默认开启）；直播间默认不接管，可在设置里单独打开。
  <small>视频流单击暂停功能是为了防止抖音原本的单击功能被脚本拦截，实测优化代码后没有碰到过，不过为了防止意外，保留了代码。</small>
* **面板外观与配置同步**：设置面板支持液态玻璃外观，真透镜折射与按压反馈可单独开关；开启「跨域名同步配置」后，配置会在抖音各子域名间共用。
* **集中式设置面板**：`Alt+S` 从屏幕中央唤出（快捷键可自定义），`Esc` 或点击面板外关闭；面板限高可滚动防溢出，内含开关、倍速与快捷键设置、轮询间隔、滚轮步进、黑名单、摄像头小窗选择器与排障诊断，无浮动按钮遮挡画面。

## 交互与快捷键

* **Alt + S / Esc**：打开 / 关闭设置面板（快捷键可改）。
* **Shift + 1**：切到原速 1.0x（快捷键可改）。
* **Shift + 2**：切到设定倍速，默认 2.0x（快捷键与倍速值都可改）。
* **左键长按**：模拟 `D` 键，仅在视频流页生效，直播间自动排除以免误触旋转屏幕。
* **中键**：视频流页切评论区；直播间按顶栏真实按钮收起 / 展开聊天室。
* **滚轮音量**：画面内滚轮调音量（仅直播间）；同时接管抖音原生「悬停音量图标」滚轮，改为固定步进、不受系统滚动行数影响，步进可在设置里调 1~20%，带居中提示。
* **双击画面**：模拟 `Y` 键切换网页全屏，取代原来的点赞。
* **左键单击画面**：视频流页播放 / 暂停（默认开启；与长按、双击互不冲突）。
* **空格键**：播放 / 暂停。
* **拖动摄像头小窗**：按住任意位置拖动；四角拖拽改大小；面板里「位置复位」恢复默认。

## 隐私与透明度

* **只在抖音域名运行**：仅匹配 `www.douyin.com` 与 `live.douyin.com`，`@grant none`，不需要账号授权或额外的浏览器权限。
* **真实人数怎么取数**：为把「10万+」换成精确人数，脚本会在页面里只读地包裹 `fetch` / `XMLHttpRequest` / `WebSocket` 的响应（克隆一份文本扫描，不改动返回内容），并从 React 内部状态、全局变量与内联数据取数；轮询时按你设定的间隔重新请求「页面自己请求过的」抖音接口，并带上当前站点 Cookie，否则拿不到已登录可见的人数。
* **声音与点击的接管**：静音礼物音效时会包裹网页的媒体播放入口，只静音礼物 / 音效类媒体并主动避开主视频；双击全屏时会在很短的时间窗内拦截抖音的点赞点击，避免误触。这些接管只在对应页面和开关开启时生效。
* **本地存了什么**：开关配置写在 `localStorage`，视频画质偏好写在 `sessionStorage`，直播画质偏好与小窗位置写在本地存储；开启「跨域名同步配置」后会额外在 `.douyin.com` 写一份配置 cookie，关掉就不再写。清除网站数据即可全部抹掉。
* **自动跳过怎么做**：优先模拟按「下一条」；选「点不感兴趣」时会点击抖音自己的菜单项，不产生站外请求。
* **排障诊断**：面板里的「复制…诊断」只把结构化文本复制到剪贴板，便于反馈问题，不上传、不改动设置。
* **没有这些东西**：脚本没有统计、追踪、广告或挖矿代码，也没有把数据发往第三方服务器的上报逻辑。
